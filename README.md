# 記録ベース

授業や活動の記録（写真・目標・できたこと・感想など）をA4縦一枚にまとめ、単元ごとに積み重ねて振り返るiPad向けアプリ。記録はiPadの中だけに保存し、外には送りません。

- 設計書：[docs/design.md](docs/design.md)

## iPadでの使い始め

1. SafariでアプリのURLを開く。
2. 共有ボタン（□↑）→「ホーム画面に追加」。
3. 以後は**必ずホーム画面のアイコンから**開く（Safariで開くと、記録が別々になります）。

ホーム画面のアイコンを削除すると、記録も消えます。

## 手元での確認

```bash
python3 -m http.server 8795
```

http://localhost:8795 を開く。テストは `npm test`。
